# Rubric

Smart intern-to-startup matching for the QSTP Internship Program.

Rubric turns one shared candidate pool into per-startup shortlists — collecting applications once and using AI to match every candidate against multiple host-startup profiles at the same time, with ranked results and fit reasons.

Built for **QSTP "BUILD FOR QSTP" — Challenge 2: CV Matching Bottleneck.**

## Status

Early scaffold. Build in progress.

## Planned stack

- Next.js (App Router) + TypeScript
- Tailwind CSS + shadcn/ui
- Supabase (Postgres) or SQLite/Prisma
- Claude API for ranking, screening-question generation, and AI-authenticity scoring
- Deployed on Vercel (public application link + live demo)
