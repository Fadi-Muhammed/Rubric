The living rubric
One shared pool of intern applicants, ranked for each host startup. This document is the build reference: every screen in light and dark, every key state as its own frame, and a motion note beside each frame describing exactly how it should move.
Motion budget
180–240ms transforms, 120ms opacity. Nothing longer than 320ms.
Default spring
stiffness 420 · damping 34 · mass 1. One spring for the whole product.
Stagger
List children 28ms apart, capped at 10 — later rows arrive already settled.
Never
No spinners, no bounce overshoot on text, no fade-only page changes.
Frames are referenced by id — 3e is the expanded row, 4a the strict authenticity threshold. Each frame is a real, inspectable layout at 1:1 scale; nothing here is a screenshot.

01
Recruiter dashboard
Open roles as quiet cards. Three numbers per card — applicants, cover letters, new today — set in Fraunces so the page scans as figures first, chrome second.
1a
Default — light
Enter: cards fade in from opacity 0 / translateY 8px, 28ms stagger in reading order. The three stat numbers count up from 0 over 420ms with an ease-out — commas settle only at the end, never mid-count.
1b
Loading skeleton — light
Loading: band opacity breathes 0.6→1 over 1.1s, cards offset 90ms apart so the grid reads as a wave, not a strobe. Bands occupy the exact geometry of the real card, so the swap to 1a is a crossfade with zero layout shift.
1c
Hover / focus — light
Hover: border to accent, translateY −2px, ambient shadow in over 160ms. The “Match pool” pill fades and slides 4px from the right, 40ms behind the lift. Keyboard focus shows the same state plus a 2px accent ring, no lift.

02
Job & intake builder
Three steps: public role details, the application form, then review and publish. The step rail is the only persistent chrome; the column below it is a single 880px measure so the eye never re-anchors between steps.
2a
Step 1 · Role details — light
Improve with AI: the pill fills accent and its label crossfades to “Rewriting…”; the textarea keeps its height while replaced text arrives as a 200ms word-by-word reveal (no cursor jump, no skeleton). An inline “Undo rewrite” chip appears for 8s, then fades.
2b
Step 2 · Form builder — light
Toggle: knob travels on the default spring, track colour 120ms; the row's label and tag crossfade between ink and secondary. Add suggested question: the card lifts out of the right panel and lands in the list as a shared-element move — the list reflows with FLIP, the panel closes its gap in the same frame.
2c
Step 3 · Review & published link — light
Publish: button label swaps to a 22px check that draws in 240ms; the green confirmation panel expands from 0 height with its content held at opacity 0 until 60% of the way open. Copy link flips the button to “Copied” for 1.4s — no toast.

03
Match pool → startup
Pick a host startup; the shared pool re-ranks against it. Every row carries a score dial and expands in place into its fit reasons — the same row can also promote itself into the full drawer. Five frames trace the whole arc.
3a
Pre-match — light
Idle: the dashed empty dial rotates one full turn every 24s — the only ambient motion in the product. On “Rank for…”, it becomes the header dial via shared element while the copy block fades out 8px upward.
3b
Scoring · skeleton — light
Scoring: seven skeleton rows at descending opacity imply depth beyond the fold. The subline is a live count (“Scoring 612 applicants…”) that ticks, so progress is legible without a bar or spinner.
3c
Results staggering in — light
Arrival (frozen mid-transition): rows translateY 10px → 0 with opacity 0 → 1, 28ms apart. Each dial arc sweeps 0 → value over 520ms on ease-out; the numeral counts up in step with its arc. Authenticity pills scale 0.94 → 1 at 60% of the row's own progress.
3d
Ranked results — light
Settled: row hover tints the surface 3% and reveals the chevron at full opacity in 120ms — the row itself never moves, so pointer aim into the chevron is stable.
3e
Row expanded · fit reasons — light
Expand: height animates to auto on the default spring (220ms); the three reason cards fade up 6px, 40ms apart, starting at 50% of the expansion. Chevron rotates 180°. Rows below reflow with FLIP — they translate, they do not re-render.
3f
Drawer open from row — light
Shared element: the row's 36px dial flies to the drawer's 88px dial along a single arc — one element, scaled, never cross-faded. The name travels with it and settles into Fraunces 28px. Panel enters from +32px x with the scrim at 0 → full over 160ms. Esc reverses the exact same path.

04
Threshold slider
Every candidate carries a “% AI-written” badge on the green → amber → red scale, computed from screening answers and cover letter. The slider sets the hide-above line: strict removes rows from the ranking, permissive keeps them and flags them red.
4a
Threshold 20% · strict — light
Drag down: hidden rows collapse height to 0 while fading, 20ms apart from the bottom up; survivors renumber with a 6px vertical FLIP and the rank numerals crossfade. Header count and the banner text retarget continuously as the knob moves — the list follows the thumb, it does not wait for release.
4b
Threshold 100% · permissive, flagged — light
Drag up: returning rows expand from 0 height and land already at their new rank; the red flag tint washes in over 180ms and the “Signals” cell crossfades to “Flagged · review answers” for anything at 50% or above. Slider knob itself has no spring — it is 1:1 with the pointer.

06
Public application page
What the intern sees: one 680px column, only the fields the recruiter enabled, required resume dropzone, optional cover letter, and every screening question mandatory. Calm enough to be trusted with a resume.
6a
Empty · first field focused — light
Focus: border to accent plus a 3px accent-at-8% ring, 120ms, no scale. Submit stays visibly disabled with a live count of what's missing — never a shake, never an error state before the first attempt.
6b
Resume drag-over — light
Drag-over: dashed border becomes 1.5px solid accent with an accent-8% wash; the icon tile fills accent and the label crossfades to the file name. Zone grows 0px — padding compensates for the thicker border so nothing below shifts.
6c
Completed · ready to submit — light
Upload settled: icon tile crossfades to green, sub-label swaps to size and parse status. Progress bar in the header animates its width on the default spring. Submit crosses from disabled tint to solid accent in 140ms once the last requirement clears.

⌘K command palette
Startups, candidates and actions in one list. Running a match and setting the authenticity threshold are both reachable without touching the mouse.
7a
Open · recents — light
Open: panel scales 0.98 → 1 with 6px downward travel, 180ms; scrim 0 → full in 120ms. Rows do not stagger on open — the list must be readable on frame one.
7b
Typing “sadeem” — light
Filtering: panel height animates on the default spring; group headers and rows crossfade in place, no vertical travel. The selection bar is a single element that slides between rows in 90ms — it never blinks off.
